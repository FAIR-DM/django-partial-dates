# Contributing

For anyone working on the package: how to set up, the standards every change follows, the
decisions behind its design and what is planned next.

Everyone taking part in the project, in issues, pull requests and discussions, follows the
[FAIR-DM code of conduct](https://github.com/FAIR-DM/.github/blob/main/CODE_OF_CONDUCT.md).
Report a problem with someone's conduct to [developers@fairdm.org](mailto:developers@fairdm.org).
